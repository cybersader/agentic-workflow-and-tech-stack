## Session model checker

- Added `profiles/claude-global/claude-session-models.sh`, symlinked as `~/.local/bin/claude-session-models`. Run as `! claude-session-models` inside a session to print the enclosing `claude` process's main model, worker default/lock, and each `--agents` worker model. It reports whether GPT-6 Sol/Luna are reachable. It is read-only: it inspects `/proc/<pid>/cmdline` and `environ` and sends no inference. Motivation: running sessions keep the models they launched with, so after the GPT-6 rollout the only reliable check is the live process, not the snippet source.
