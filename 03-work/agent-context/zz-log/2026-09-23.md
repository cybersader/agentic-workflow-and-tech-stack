## GPT-6 Sol and Luna rollout

- OpenAI released GPT-6 Sol (`gpt-6-sol`) and GPT-6 Luna (`gpt-6-luna`) on 2026-09-22. The local CLIProxyAPI catalog advertised both. With the human's approval, one minimal Messages-API request per model confirmed that each exact model is served (309 input / 5 output tokens each). Catalog presence alone was not treated as route proof.
- Human decisions: GPT-6 Sol replaces `gpt-5.6-sol` as the default, and Luna is an explicit worker only.
- **Launchers:** every Sol-main lane (`claudex`, `claudexm`, `claudexma`, `claudexo`) now runs `gpt-6-sol`. Every Sol-locked lane (`opusx`, `opus55x`, `fablex`, `astrax`) sets `CLAUDE_CODE_SUBAGENT_MODEL` and `AGENT_GUARD_SUBAGENT_MODEL_LOCK` to `gpt-6-sol`. Each of the six session-scoped agent maps that expose `sol-worker` now points it at `gpt-6-sol` and adds `luna-worker` → `gpt-6-luna` for clerical and lighter bounded work. No lane defaults to Luna.
- **Resume identity:** `ccx` treats `gpt-5.6-sol`, `gpt-6-sol`, and `gpt-6-luna` as distinct identities. A 5.6-Sol session resumed on a Sol lane takes the existing full-history fork path, the same as an Opus 5 ↔ 5.5 resume.
- **Guard, policy, and dispatcher:** both models were added to the `local-proxy` route and the weekly OpenAI/Codex pool. Neither is premium. The direct-agent map is now `sol-worker` → `gpt-6-sol` and `luna-worker` → `gpt-6-luna`. `gpt-5.6-sol` stays admitted as an explicit legacy model. Policy, guard, embedded dispatcher, and installer validation moved together. The canonical dispatch-block pin changed `96935beb…` → `db9fa1f1…`, and the dispatcher file changed `3026ad01…` → `4ea59779…`.
- **Review correction:** the launcher worker had added hard `gpt-6-sol` and `gpt-6-luna` catalog gates to `opus55xm`. On that flexible lane, Sol and Luna are optional workers covered by degraded continuation, so a Codex-side outage should not block Opus 5.5. The gates were removed there. `opus55x` keeps its Sol gate because Sol is that lane's locked worker route. Tests now assert the absence.
- **Unchanged:** the OpenRouter `sol-or-high` / `sol-or-worker` alias stays on 5.6 Sol until that route is verified separately.
